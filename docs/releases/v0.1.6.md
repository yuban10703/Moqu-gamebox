## 本版更新

- 新增三款玩法，内置游戏达到 **20 款**：**井字棋**（三档对手 + 双人同屏）、**空当接龙**（抽 1 张 / 抽 3 张两档，含自动收牌与撤销）、**数织**（16 道手写题，5×5 与 10×10）。
- 牌桌玩法支持「牌堆」布局：13 个牌堆各自可点，**空牌堆也能点** —— 空当接龙的「K 进空列 / A 进空基础堆」在真机上实测可走通。
- 棋盘支持「外侧线索带」：数织的行 / 列提示画在棋盘外，不占格子；缺省不渲染，其余玩法的外观零变化。
- 修掉三处实机走查发现的问题：结果面板漏出 `⟦key⟧`（现在缺词就不显示那一行，7 款玩法受益）、空当接龙抽牌堆抽空后误显示「1 张」（现为 0 张，13 个牌堆合计恒为 52）、井字棋和局后结果面板没有「撤销」（现在和棋也能退一手；另外四款棋类同步）。
- 新增守卫测试：i18n 文案里的 markdown 残留（21 个字典 / 1508 条值）、牌桌牌堆与空堆布局、结果面板最佳行、抽牌堆回收、撤销口径。
- 提示：井字棋「挑战」档是完整 minimax 对手，它不会失误 —— 你能拿到的最好结果是和棋。
