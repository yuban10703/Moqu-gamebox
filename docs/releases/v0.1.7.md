## 本版更新

- **修掉「装上就白屏」**：系统 WebView 版本过低时，改为显示一屏看得懂的提示（当前版本 / 需要 110 及以上 / 到哪里更新），而不是白屏。三道防线：启动时的**原生闸**（低于门槛根本不创建 WebView，直接给原生提示页）、进界面前的**能力探测**（探容器查询与 `dvh`，缺哪项就写哪项）、以及 `index.html` 里**不依赖任何模块**的静态占位与 ES5 兜底（连脚本都跑不起来时也能看到字）。
- 最低要求写进文档：**系统 WebView ≥ Chrome 110**（容器查询 105 是挪不掉的底线，`dvh` 108 可兜底、本轮不改）。
- 启动兜底的等待放宽到 5 秒，避免「机器够新但启动慢」被误判。
- 已在真机核验：正常设备不受影响（首页 20 款游戏照常）；人为模拟低版本时显示提示页而非白屏。
