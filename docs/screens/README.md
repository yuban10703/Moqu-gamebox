# 截图索引

本目录是验收证据。命名约定（2026 起）：

- `library-<N>games-p6.png` —— P6Plus 首页（N 款游戏）的历史留档（`<N>` 是数字占位；最新一张停在 11 款，当前已是 14 款）；
- `game-<英文id>-portrait.png` / `game-<英文id>-landscape-p6.png` —— 单款游戏（浏览器 / 真机）；
- `rotate-hint-p6.png` —— 「建议竖屏游玩」提示的真机证据；
- `diagnostics-p6.png` —— 诊断页真机；
- `web-*.png` —— 网页版截图。
- `readme-*.png` —— 仓库首页 README 的展示图（构建产物 + 浏览器 439×847 / 879×407 @1.5x，脚本化走到对局中途截取）。
