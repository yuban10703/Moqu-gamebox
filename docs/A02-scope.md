# A02 · 首版范围

状态：已冻结（可按变更流程调整）。

## 首版包含

| 项目 | 内容 |
|---|---|
| 平台 | Web（PWA，静态托管）+ Android APK（BOOX 优先，10.3 吋为主基线） |
| 语言 | 简体中文 + English（同版本交付，字典对齐由测试强制） |
| 网络 | **完全离线**：不申请网络权限，无账号、无后端、无遥测 |
| 存档 | 每款游戏一个进行中的局面；本机持久化；手动导出/导入备份跨设备搬运 |
| 游戏（M1/M2，本轮） | 推箱子（16 关，入门/熟练/挑战三档） |
| 游戏（M3，下一轮） | 数独（生成器 + 唯一解校验 + 笔记）、扫雷（首步安全 + 插旗模式）、2048（离散步进） |
| 盒子能力 | 游戏库、详情、统一外框（暂停/返回/重开/覆盖确认/结果页）、设置（语言/字号//计时/方向盘/线条）、数据管理（导出/导入/清除/备份恢复）、诊断页、帮助页 |
| 输入 | 触摸按钮（主）、滑动（补充）、方向键 / U / R / Esc / PageUp / PageDown、实体翻页键 |

## 首版明确不做

- 动画、过渡、循环加载、闪烁提示；
- 像素级局部刷新承诺、零残影承诺；
- 账号、云同步、排行榜、在线对战（H05 之后再评估）；
- 动态代码分发、内容包（H06）；
- 除推箱子之外的游戏（M3 起）；
- iOS、文石以外的墨水屏厂商适配（先保证通用模式不崩、可用）。

## 范围判断依据

- 「首版每款做到可完整游玩、可保存恢复，再扩展数量」；
- 推箱子用于打通双端完整流程：状态离散、无随机、内容可程序化验证；
- 数独的 9×9 小屏交互风险最高，因此在 M1 阶段用静态样例提前验证
  （见 `docs/A04-screens.md` 的「数独交互预验证」）。
